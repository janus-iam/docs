Janus is built on Keycloak. Each realm is a strictly isolated space: a user exists in **one realm only**.

The three realms are named in [Janus Realms](/governance/realms):

| Realm | Display name | Role |
| --- | --- | --- |
| `prod` | canens | Live users and services |
| `dev` | proca | Development, away from production |
| `ops` | carna | Operations accounts that run Janus |
