[janus-iam/media-kit](https://github.com/janus-iam/media-kit) contains two image files. The commit that added them calls them sample assets. There is no other text in the repository.

| File | Format | Size |
| --- | --- | --- |
| [pieuvre.jpg](https://github.com/janus-iam/media-kit/blob/main/pieuvre.jpg) | JPEG | 1376×768 |
| [paresseux.png](https://github.com/janus-iam/media-kit/blob/main/paresseux.png) | PNG | 1536×1024 |

`pieuvre.jpg` is a sheet of a purple octopus character in several poses. `paresseux.png` is a sheet of a sloth character in several poses. One of those poses holds a sign that reads "Une meilleure santé pour tous".
